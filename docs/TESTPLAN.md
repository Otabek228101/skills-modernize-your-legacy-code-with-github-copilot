## Scope and implementation notes

- The COBOL amount fields use `PIC 9(6)V99`, which represents a non-negative amount with up to six whole digits and two fractional digits. The menu choice is `PIC 9`.
- The current code does not explicitly validate negative, non-numeric, or out-of-range amounts, nor does it define a user-facing error for them. Their handling may depend on COBOL runtime input behavior; agree on desired Node.js behavior with stakeholders rather than assuming a rule from this implementation.
- The balance is stored in working storage, not in a file or database. It is shared by operations during one running process and resets to `1000.00` on a new run.
- Actual Result and Status are intentionally left for execution. Record the observed result and mark each case Pass or Fail after stakeholder or implementation testing.
